# Support

DevKitty support is focused on bugs, accessibility issues, documentation problems, and tool requests.

---

## What support covers

- Bug reports
- Broken tool behaviour
- Accessibility issues
- Documentation corrections
- Feature requests
- Tool requests
- Repository configuration issues

---

## What support does not cover

- Account-specific private data issues
- Secret recovery
- Payment disputes
- Personal coding help unrelated to DevKitty

---

## Best way to ask for help

Use the issue templates when possible.

Include:

- A clear summary
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Browser and version
- Screenshots if useful

---

## Response expectations

Support requests are reviewed as the project grows.

Clear reports are easier to triage and fix.

---

## Security-related support

Do not open a public issue for a security problem.
Use `SECURITY.md` for private reporting.
