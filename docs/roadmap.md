# DevKitty Roadmap

> Building the world's most refined collection of developer tools.

This roadmap describes the current direction of DevKitty.
The sequence may evolve, but the product principles remain fixed: speed, privacy, consistency, and craftsmanship.

---

## Phase 1 — Foundation

Status: In progress

### Objectives

- Premium brand identity
- Dark-mode-first interface
- Strong design system
- Responsive layout
- Fast global navigation
- Clean documentation structure

### Core tools

- JSON Formatter
- JSON Validator
- JSON Compare
- Base64 Encode / Decode
- URL Encode / Decode
- JWT Decoder
- UUID Generator
- Password Generator
- SHA-256 Generator
- Regex Tester
- Unix Timestamp Converter
- QR Code Generator
- HEX ↔ RGB Converter
- Color Picker
