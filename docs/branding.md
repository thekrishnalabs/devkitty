# DevKitty Branding

> DevKitty is a premium developer tool brand built around silent luxury, precision, and trust.

This document defines the official branding rules for DevKitty.

---

## Brand Identity

- Name: DevKitty
- Domain: devkitty.in
- Category: Developer tools platform
- Positioning: Premium, privacy-first, browser-based developer workstation
- Tone: Calm, technical, confident, refined

---

## Logo

The official DevKitty logo is final.

### Rules

- Do not redraw the logo.
- Do not distort the logo.
- Do not add shadows, glow, or gradients to the logo.
- Do not change the proportions.
- Do not place the logo on busy or low-contrast backgrounds.
- Keep generous clear space around the logo.

### Usage

- Use the full wordmark in marketing and docs headers.
- Use the icon mark in favicon, app icon, loading states, and compact nav areas.
- Use the monochrome version whenever the background requires it.

---

## Official Colour System

### Base

- Background: `#0B0C0D`
- Sidebar: `#101112`
- Surface: `#171819`
- Surface hover: `#1E2021`
- Border: `#292A2B`

### Text

- Primary text: `#F1F0EC`
- Secondary text: `#A19F98`
- Muted text: `#737373`

### Accent

- Primary accent: `#C47A3A`
- Accent soft: `rgba(196, 122, 58, 0.18)`

### Status

- Success: `#4F8F6B`
- Warning: `#B78A3B`
- Error: `#C84A4A`

Copper is the only brand accent.
No additional accent colours are permitted.

---

## Typography

### Fonts

- Display: Geist
- Body: IBM Plex Sans
- Mono: JetBrains Mono

### Typography rules

- Display text stays restrained.
- Body text stays clear and readable.
- Code, hashes, JSON, and technical output use monospace.
- Do not mix decorative fonts into the product UI.

---

## Visual Style

DevKitty uses a silent-luxury design language.

### Visual characteristics

- Dark
- Minimal
- Editorial
- Technical
- Precise
- Timeless

### Visual rules

- Hairline borders
- Strong spacing system
- Very subtle motion
- No glassmorphism
- No neon
- No gradient-heavy layouts
- No cluttered illustrations

---

## Screenshots and Marketing Art

### Screenshot style

- Dark-mode first
- Clean, aligned layouts
- Minimal text noise
- Copper as the only visual highlight
- No random colour overlays

### Social assets

- Banner graphics stay minimal and premium
- Product screenshots show actual interface quality
- Marketing images must match the product design system

---

## Icon Style

- Outline icons only
- Lucide React icon set
- No emoji icons
- No playful shapes
- No filled cartoon styling

---

## Tone of Voice

The brand voice is direct, calm, and technical.

### Write like:

- A product team
- A technical documentation site
- A premium developer platform

### Do not write like:

- A hype-driven startup
- A generic AI SaaS landing page
- A sales-heavy funnel

---

## Brand Rules

- One accent colour only.
- No visual noise.
- No decorative clutter.
- No personality drift between pages.
- Keep the same visual language across tools, docs, and marketing.

---

## Brand Promise

DevKitty feels like a premium operating system for developers.
