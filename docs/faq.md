# DevKitty FAQ

## What is DevKitty?

DevKitty is a premium browser-based developer tools platform. It collects high-use utilities into one consistent, privacy-first workspace.

---

## Is DevKitty free?

Yes. DevKitty provides free tools with zero signup.

---

## Does DevKitty require an account?

No account is required for core usage.

---

## Does DevKitty process data locally?

Whenever technically possible, yes. DevKitty is built with a client-side-first approach.

---

## Why does DevKitty exist?

Developers use many small utility sites every day. DevKitty brings the most useful ones into one premium product with one design language.

---

## What kind of tools will DevKitty include?

DevKitty includes and plans to include tools across:

- JSON and data
- Encoding and cryptography
- Text utilities
- Regex
- CSS
- HTML
- JavaScript
- SQL
- Date and time
- Color tools
- Image tools
- API and network tools
- Security helpers
- Browser utilities

---

## Why does DevKitty look so minimal?

Because the product is built for speed, clarity, and trust. The interface must stay out of the way.

---

## Can the community request new tools?

Yes. Tool requests are encouraged through the issue templates.

---

## Is DevKitty open source?

The public repository is open and documentation-focused. The product architecture and implementation can remain separate depending on release strategy.

---

## What makes DevKitty different from other tool websites?

DevKitty focuses on:

- Silent-luxury branding
- One consistent design system
- Browser-first behaviour
- Zero signup
- Privacy-first processing
- Professional documentation

---

## What is the long-term goal?

The long-term goal is to make DevKitty the first place developers open when they need a utility tool.
