# Markdown Tools

Markdown tools support writing, conversion, previewing, and documentation workflows.
They are essential for README files, docs, blog posts, notes, and developer communication.

---

## Purpose

The Markdown family covers preview, conversion, formatting, and content helpers.
These tools must make documentation work faster and clearer.

---

## Included Tools

### Markdown Preview
Renders Markdown into a clear live preview.

### Markdown to HTML
Converts Markdown into HTML markup.

### HTML to Markdown
Converts HTML into Markdown where a clean mapping exists.

### Markdown Formatter
Cleans up Markdown spacing and structure.

### Table Generator
Builds Markdown tables from structured data.

### README Generator
Creates starter README content for projects and tools.

### Changelog Generator
Creates changelog-style markdown sections.

### Documentation Snippet Helper
Generates reusable blocks for documentation.

### Task List Builder
Builds structured Markdown task lists.

### Link Checker Helper
Surfaces broken or unsafe links in documentation workflows.

---

## Interaction Standards

Markdown tools must support:

- Paste input
- Live preview where useful
- Copy output
- Download output
- Large document handling
- Mobile-safe layout
- Clear formatting feedback

---

## Output Standards

Markdown output must remain readable in raw form.
If the tool generates HTML or structured output, the mapping must stay obvious.

---

## Common Use Cases

- README editing
- Documentation writing
- Blog drafts
- Issue templates
- Pull request descriptions
- Product notes
- Changelog writing

---

## Quality Rules

Markdown tools must avoid over-formatting.
The output should improve clarity without changing meaning.
