# JavaScript Tools

JavaScript tools support formatting, inspection, conversion, and workflow utilities for frontend and backend developers.
They are essential for daily JavaScript work.

---

## Purpose

The JavaScript family covers source formatting, minification, debugging, conversion, and developer helpers.
These tools must be clear, fast, and reliable.

---

## Included Tools

### JS Formatter
Formats JavaScript into readable, consistent structure.

### JS Minifier
Reduces JavaScript size by removing unnecessary whitespace and comments.

### JS Diff
Compares two JavaScript snippets and highlights differences.

### Console Playground
Helps test console output and debug snippets.

### ES Module Converter
Converts module-style code for different JavaScript packaging styles.

### JSON Schema Generator
Creates starter schema structures from example data.

### Faker Data Generator
Generates realistic test data for development and demos.

### Commit Message Generator
Suggests clean commit message drafts from short context.

### Code Comment Generator
Creates documentation-style comments for code snippets.

### Error Explainer
Turns runtime-style errors into clearer developer-friendly explanations.

### Promise Helper
Shows promise flow and async behaviour in an understandable way.

### Array and Object Playground
Helps inspect common JavaScript data structures.

---

## Interaction Standards

JavaScript tools must support:

- Paste input
- Copy output
- Clear error messaging
- Large snippet handling
- Formatting presets where useful
- Mobile-safe layout

---

## Output Standards

Output must preserve semantics.
If a transformation changes syntax or module style, that change must be explicit.

---

## Common Use Cases

- Frontend debugging
- Backend snippets
- Documentation work
- Refactoring
- Test data generation
- Commit workflow support
- Async behaviour inspection

---

## Quality Rules

JavaScript tools must not hide important syntax changes.
The user must always understand what transformation was applied.
