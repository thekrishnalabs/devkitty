# DevKitty Tools

> A curated index of developer tools designed with one consistent system.

This directory documents the tool families that power DevKitty.
Each category contains focused utilities that solve one problem clearly.

---

## Tool Principles

Every DevKitty tool follows the same standards:

- One job per tool
- Fast interaction
- Clear labels
- Minimal friction
- Client-side whenever possible
- Privacy-first behaviour
- Strong keyboard support
- Consistent layout

---

## Primary Tool Families

- `json.md` — JSON and data utilities
- `encoding.md` — Encoding, hashing, and cryptography helpers
- `css.md` — CSS and visual design utilities
- `images.md` — Image processing helpers
- `network.md` — API, URL, and network utilities
- `upcoming.md` — Planned and exploratory tools

---

## Standard Tool Page Shape

Every tool page uses the same structure:

1. Title
2. Description
3. Input area
4. Output area
5. Action buttons
6. Related tools
7. Notes or FAQ when needed

---

## Tool Quality Bar

A tool belongs in DevKitty only if it is:

- Useful on its own
- Easy to understand
- Reliable on mobile and desktop
- Consistent with the visual system
- Worth revisiting often

---

## Future Tool Coverage

As DevKitty grows, this index expands into categories such as:

- HTML utilities
- JavaScript utilities
- SQL utilities
- Markdown tools
- Browser utilities
- Security helpers
- Date and time tools
