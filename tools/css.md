# CSS Tools

CSS tools help with layout, visual debugging, spacing, sizing, and styling workflows.
They are essential for frontend development and design work.

---

## Purpose

The CSS family covers generation, conversion, inspection, and visual experimentation.
These tools must support quick iteration and clean visual feedback.

---

## Included Tools

### Colour Picker
Selects colours and exposes values across formats.

### HEX ↔ RGB Converter
Converts HEX values to RGB and RGB values to HEX.

### RGB ↔ HSL Converter
Converts RGB and HSL values in both directions.

### RGB ↔ CMYK Converter
Converts screen and print colour formats.

### Gradient Generator
Builds linear and radial gradients with preview output.

### Box Shadow Generator
Creates shadow values with live preview.

### Border Radius Generator
Builds radius values and shape previews.

### CSS Clamp Generator
Generates responsive clamp() values for typography and spacing.

### CSS Variables Generator
Turns design tokens into reusable custom properties.

### Tailwind Colour Generator
Creates palette values that map into Tailwind-style colour scales.

### CSS Triangle Generator
Builds triangle shapes from border manipulation.

### Flexbox Playground
Visualises flex container and child alignment behaviour.

### Grid Generator
Builds grid templates and previews layout behaviour.

### Cubic Bezier Editor
Edits easing curves and previews motion behaviour.

### CSS Filter Generator
Builds filter chains for UI and image experimentation.

### Transform Playground
Tests translate, rotate, scale, and skew values.

### Aspect Ratio Generator
Generates ratio-safe styles for responsive containers.

### CSS Unit Converter
Converts between px, rem, em, %, vw, and vh where appropriate.

### CSS Minifier
Removes whitespace from CSS output for production use.

---

## Interaction Standards

CSS tools must support:

- Live previews where useful
- Copy output
- Reset controls
- Preset values
- Responsive viewport behaviour
- Mobile-friendly controls
- Clear labels for each control

---

## Output Standards

Every CSS tool output must be readable and immediately usable.
Generated code must be easy to copy into a project without cleanup.

---

## Common Use Cases

- UI development
- Component styling
- Design system work
- Animation tuning
- Spacing and sizing checks
- Layout debugging
- Theme building

---

## Visual Quality Rules

Preview panes must feel precise and polished.
Controls must stay aligned and uncluttered.
The tool should feel like part of the same DevKitty workstation.
