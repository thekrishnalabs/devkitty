# JSON Tools

DevKitty treats JSON tools as core utilities because JSON is used across APIs, config files, automation, and data exchange.

---

## Purpose

The JSON family covers formatting, validation, comparison, conversion, and inspection.

These tools must be fast, deterministic, and easy to trust.

---

## Included Tools

### JSON Formatter
Formats raw JSON into readable, indented output.

### JSON Validator
Checks whether JSON is syntactically valid and reports errors clearly.

### JSON Compare
Compares two JSON values and highlights structural differences.

### JSON Minifier
Removes unnecessary whitespace from JSON.

### JSON Beautifier
Produces clean, human-readable JSON output.

### JSON Path Tester
Tests JSONPath expressions against structured data.

### JSON Schema Viewer
Displays schema structure and validation expectations.

### JSON Schema Generator
Creates a starter schema from example JSON.

### JSON to CSV
Converts JSON arrays into tabular CSV output.

### CSV to JSON
Converts rows and columns into JSON objects.

### JSON to YAML
Translates JSON structure into YAML.

### YAML to JSON
Translates YAML structure into JSON.

### JSON to XML
Converts JSON into XML where a mapping is possible.

### XML to JSON
Converts XML into JSON structure.

### Mock JSON Generator
Generates realistic sample JSON for testing and demos.

---

## Interaction Standards

JSON tools must support:

- Paste input
- File input where relevant
- Copy output
- Download output
- Clear validation errors
- Large payload handling
- Mobile-safe layout

---

## Output Standards

JSON output must preserve structure clearly.
Errors must point to the exact line or field where possible.
